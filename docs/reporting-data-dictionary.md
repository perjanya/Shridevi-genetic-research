# Reporting data dictionary

| Measure | Definition |
| --- | --- |
| Study scope | Each stable study ID is counted once. Department filters use confirmed lead or collaborator assignments. Historical distribution uses the latest recorded study snapshot before the end of the cutoff day in Asia/Kolkata. The viewer must retain current access. |
| Reporting period | Calendar or programme-aligned quarter, half year or year, or inclusive custom dates. The current date caps live actuals for future-ending periods. |
| Events in period | Recorded effective dates inside the inclusive range, using the records known at the cutoff. |
| Cumulative | Records through the cutoff, starting at the programme start when configured. Laboratory activity months use the applicable programme year. |
| Feasibility and endorsement | Completed feasibility screening. PI endorsement requires confirmation from an authorized role and a recorded evidence reference. |
| Activation and completion | Activation is the confirmed authorization date. Completion requires data lock, confirmed PI-approved final report and required closeout, or confirmed documented inapplicability of closeout. |
| Applications and awards | One record per external application. Count dated submissions and written awards separately. Grant success is awards divided by awards plus declines through the cutoff. Pending applications appear separately. |
| Manuscripts and indexed papers | One record per manuscript. Count the submission once. Count an indexed paper once using its earliest recorded acceptance or publication date after indexing is verified. |
| Approved laboratory month | A month with at least one confirmed research assay or project QC record. Confirmed-zero entries and unreviewed entries do not count toward the target. Months without records display as unreviewed. |
| Timeliness | Applicable milestones due in the period and completed by the recorded deadline divided by applicable milestones due in the period. Completion retains the deadline recorded at that time. Deadline changes are audited. |
| Turnaround | Median calendar days for intervals ending in the period, with the interval count. SRC and IEC intervals can be classified as external decision or coordinator follow-up. These classifications describe the logged interval and do not estimate fractional waiting time. |
| Recruitment and sample delivery | Aggregate actuals through cutoff divided by the corresponding target for the same scoped projects. Projects with unknown targets are excluded from the comparable rate. |
| Rejections and repeats | Recorded rejections or repeats divided by the processed counts for the same records in the period. Unknown values are excluded from the matching denominator. |
| Budget and spend | Totals are comparable only where a study has both approved budget and spend recorded. Zero is a recorded amount. PI-managed cost is a separate funding breakdown field. |
| Experience and closure | Anonymous campaigns with fewer than five reportable responses are suppressed, including anonymous question counts below five valid ratings. Blank or not-applicable ratings are excluded. Opened, due and resolved corrective actions count separately. |
| Target versions | Settings hold planned or approved target values by programme cycle. Selecting a cycle applies its saved settings. An unfiltered report uses active cycle settings for its target comparison. A frozen review saves period, filters, target version, results, findings and assigned actions together. A correction creates a new version. |

The three-year planning baseline is 25 proposals. The Year 3 completion target is 15 of 25 planned proposals (60%). The live concept count remains independent.

The scorecard keeps feasibility, acceptability, execution fidelity, costs and sustained activity visible separately. [Proctor et al., Outcomes for Implementation Research](https://pmc.ncbi.nlm.nih.gov/articles/PMC3068522/)
